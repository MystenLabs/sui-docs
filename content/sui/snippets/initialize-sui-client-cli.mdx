Before publishing your code, you must first initialize the Sui Client CLI, if you haven't already. To do so, in a terminal or console at the root directory of the project enter `sui client`. If you receive the following response, complete the remaining instructions:

```
No sui config found in `<FILE-PATH>/.sui/sui_config/client.yaml`, create one [Y/n]?
```

Press <kbd>Enter</kbd> or enter `Y` to proceed. The CLI generates an Ed25519 key pair for a new address, writes `client.yaml` with the Testnet, Mainnet, Devnet and Localnet environments configured, and sets Testnet as the active environment. Now you should have a Sui address set up. See [Configure a Sui client](/getting-started/onboarding/configure-sui-client) for details.
