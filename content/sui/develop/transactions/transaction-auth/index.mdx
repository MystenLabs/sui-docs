Transaction authentication on Sui covers keys, addresses, signatures, key derivation (BIP-32, BIP-44, BIP-39), and signature requirements. The following subtopics detail each one.

## How are Sui transactions signed and authenticated?

To sign transactions, Sui supports multiple authentication methods, from standard cryptographic key pairs (Ed25519, ECDSA Secp256k1 and Secp256r1) to multisig wallets, zkLogin for OAuth-based authentication, and passkeys for biometric signing.
