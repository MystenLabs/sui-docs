gRPC offers a high-performance, efficient communication protocol that uses [Protocol Buffers](https://protobuf.dev/overview/) for fast, compact data serialization. Its strongly typed interfaces reduce runtime errors and simplify client and server development across multiple languages. 

The [Sui Full Node gRPC API](/references/fullnode-protocol) provides a fast, type-safe, and efficient interface for interacting with the Sui blockchain.

## When should I use gRPC?

Use gRPC for:

- Backend systems, indexers, and typed clients.
- Low-latency point lookups.
- Transaction submission and simulation.
- Filtered queries over checkpoints, transactions, and events.
- Streaming subscriptions with server-side filtering.

## When should I use something else?

Consider [GraphQL RPC](/develop/accessing-data/graphql/graphql-rpc) for:

- Frontends
- Tools
- Dynamic-language clients
- Queries that join multiple resource types

The node's retention limits full node gRPC. For point lookups beyond that retention, query an [Archival Service](/develop/accessing-data/archival-store) endpoint directly. The Archival Service offers higher retention than a full node.
