Description of a transaction, the unit of activity on Sui.


```graphql
type Transaction implements Node {
  digest: String!
  effects: TransactionEffects
  expiration: Epoch
  gasInput: GasInput
  id: ID!
  kind: TransactionKind
  sender: Address
  signatures: [UserSignature!]!
  transactionBcs: Base64
  transactionJson: JSON
}
```

#### [<code style={{ fontWeight: 'normal' }}>Transaction.<b>expiration</b></code>](#)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Epoch</b></code>](/references/sui-api/sui-graphql/beta/reference/types/objects/epoch.mdx) <Badge class="badge badge--secondary " text="object"/>

#### [<code style={{ fontWeight: 'normal' }}>Transaction.<b>gasInput</b></code>](#)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>GasInput</b></code>](/references/sui-api/sui-graphql/beta/reference/types/objects/gas-input.mdx) <Badge class="badge badge--secondary " text="object"/>
