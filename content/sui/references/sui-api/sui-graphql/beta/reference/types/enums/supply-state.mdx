Future behavior of a currency's supply.


```graphql
enum SupplyState {
  BURN_ONLY
  FIXED
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>SupplyState.<b>BURN&#x005F;ONLY</b></code>](#)  
The supply can only decrease.


#### [<code style={{ fontWeight: 'normal' }}>SupplyState.<b>FIXED</b></code>](#)  
The supply can neither increase nor decrease.
