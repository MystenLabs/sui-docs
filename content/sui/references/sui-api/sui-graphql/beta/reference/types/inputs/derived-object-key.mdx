Identifies a derived object under one parent object.

At most one of `version`, `rootVersion`, or `atCheckpoint` may be specified.


```graphql
input DerivedObjectKey {
  atCheckpoint: UInt53
  name: DynamicFieldName!
  rootVersion: UInt53
  version: UInt53
}
```
