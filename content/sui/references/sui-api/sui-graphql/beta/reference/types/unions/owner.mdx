The object's owner kind.


```graphql
union Owner = AddressOwner | ObjectOwner | Shared | Immutable | ConsensusAddressOwner
```




### Possible types

#### [<code style={{ fontWeight: 'normal' }}>Owner.<b>AddressOwner</b></code>](/references/sui-api/sui-graphql/beta/reference/types/objects/address-owner.mdx) <Badge class="badge badge--secondary " text="object"/> 
Object is exclusively owned by a single address, and is mutable.


#### [<code style={{ fontWeight: 'normal' }}>Owner.<b>ObjectOwner</b></code>](/references/sui-api/sui-graphql/beta/reference/types/objects/object-owner.mdx) <Badge class="badge badge--secondary " text="object"/> 
Object is exclusively owned by a single object, and is mutable. Note that the owning object may be inaccessible because it is wrapped.


#### [<code style={{ fontWeight: 'normal' }}>Owner.<b>Shared</b></code>](/references/sui-api/sui-graphql/beta/reference/types/objects/shared.mdx) <Badge class="badge badge--secondary " text="object"/> 
Object is shared, can be used by any address, and is mutable.


#### [<code style={{ fontWeight: 'normal' }}>Owner.<b>Immutable</b></code>](/references/sui-api/sui-graphql/beta/reference/types/objects/immutable.mdx) <Badge class="badge badge--secondary " text="object"/> 
Object is accessible to all addresses, and is immutable.


#### [<code style={{ fontWeight: 'normal' }}>Owner.<b>ConsensusAddressOwner</b></code>](/references/sui-api/sui-graphql/beta/reference/types/objects/consensus-address-owner.mdx) <Badge class="badge badge--secondary " text="object"/> 
Object is exclusively owned by a single adderss and sequenced via consensus.
