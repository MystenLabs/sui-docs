Identifies a dynamic field or derived object under a parent object.

At most one of `version`, `rootVersion`, or `atCheckpoint` may be specified.


```graphql
input NameKey {
  atCheckpoint: UInt53
  name: DynamicFieldName!
  parent: SuiAddress!
  rootVersion: UInt53
  version: UInt53
}
```
