Whether the currency is regulated or not.


```graphql
enum RegulatedState {
  REGULATED
  UNREGULATED
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>RegulatedState.<b>REGULATED</b></code>](#)  
A `DenyCap` or a `RegulatedCoinMetadata` exists for this currency.


#### [<code style={{ fontWeight: 'normal' }}>RegulatedState.<b>UNREGULATED</b></code>](#)  
The currency was created without a deny list.
