The balance of a particular coin type held by an address.

Balances can be held in coin objects, in the address's balance accumulator, or both.


```graphql
type Balance {
  addressBalance: BigInt
  coinBalance: BigInt
  coinMetadata: CoinMetadata
  coinType: MoveType
  totalBalance: BigInt
}
```
