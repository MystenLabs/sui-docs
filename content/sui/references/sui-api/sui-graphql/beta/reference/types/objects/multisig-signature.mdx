#### [<code style={{ fontWeight: 'normal' }}>MultisigSignature.<b>signatures</b></code>](#)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>[SignatureScheme!]</b></code>](/references/sui-api/sui-graphql/beta/reference/types/unions/signature-scheme.mdx) <Badge class="badge badge--secondary " text="list"/> <Badge class="badge badge--secondary " text="union"/> 
The individual member signatures, one per signer who participated.
Compressed signatures within a multisig do not include the signer's public key,
so `publicKey` will be `null` for simple signature schemes (Ed25519, Secp256k1, Secp256r1).
