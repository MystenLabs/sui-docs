Filter on who owns an object.


```graphql
enum OwnerKind {
  ADDRESS
  OBJECT
  SHARED
  IMMUTABLE
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>OwnerKind.<b>ADDRESS</b></code>](#)  
Object is owned by an address.


#### [<code style={{ fontWeight: 'normal' }}>OwnerKind.<b>OBJECT</b></code>](#)  
Object is a child of another object (e.g. a dynamic field or dynamic object field).


#### [<code style={{ fontWeight: 'normal' }}>OwnerKind.<b>SHARED</b></code>](#)  
Object is shared among multiple owners.


#### [<code style={{ fontWeight: 'normal' }}>OwnerKind.<b>IMMUTABLE</b></code>](#)  
Object is frozen.
