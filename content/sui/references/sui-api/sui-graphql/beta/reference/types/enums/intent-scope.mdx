An enum that specifies the intent scope for signature verification.


```graphql
enum IntentScope {
  TRANSACTION_DATA
  PERSONAL_MESSAGE
}
```




### Values

#### [<code style={{ fontWeight: 'normal' }}>IntentScope.<b>TRANSACTION&#x005F;DATA</b></code>](#)  
Indicates that the bytes are to be parsed as transaction data bytes.


#### [<code style={{ fontWeight: 'normal' }}>IntentScope.<b>PERSONAL&#x005F;MESSAGE</b></code>](#)  
Indicates that the bytes are to be parsed as a personal message.
