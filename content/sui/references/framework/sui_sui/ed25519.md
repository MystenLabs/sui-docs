<h2 id="sui_ed25519_ed25519_verify">Function <span class="code-inline">ed25519_verify</span></h2>

@param signature: 32-byte signature that is a point on the Ed25519 elliptic curve.
@param public_key: 32-byte signature that is a point on the Ed25519 elliptic curve.
@param msg: The message that we test the signature against.

If the signature is a valid Ed25519 signature of the message and public key, return true.<br/>
Otherwise, return false.
