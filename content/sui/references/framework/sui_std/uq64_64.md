Defines an unsigned, fixed-point numeric type with a 64-bit integer part and a 64-bit fractional
part. The notation <span class="code-inline"><a href="../sui_std/uq64_64#std_uq64_64">uq64_64</a></span> and <span class="code-inline"><a href="../sui_std/uq64_64#std_uq64_64_UQ64_64">UQ64_64</a></span> is based on
[Q notation](https://en.wikipedia.org/wiki/Q_(number_format)). <span class="code-inline">q</span> indicates it a fixed-point
number. The <span class="code-inline">u</span> prefix indicates it is unsigned. The <span class="code-inline">64_64</span> suffix indicates the number of
bits, where the first number indicates the number of bits in the integer part, and the second
the number of bits in the fractional part--in this case 64 bits for each.

<h2 id="std_uq64_64_UQ64_64">Struct <span class="code-inline">UQ64_64</span></h2>

A fixed-point numeric type with 64 integer bits and 64 fractional bits, represented by an
underlying 128 bit value. This is a binary representation, so decimal values may not be exactly
representable, but it provides more than 19 decimal digits of precision both before and after
the decimal point (38 digits total).

</code></pre>

<h2 id="std_uq64_64_from_quotient">Function <span class="code-inline">from_quotient</span></h2>

Create a fixed-point value from a quotient specified by its numerator and denominator.
<span class="code-inline"><a href="../sui_std/uq64_64#std_uq64_64_from_quotient">from_quotient</a></span> and <span class="code-inline"><a href="../sui_std/uq64_64#std_uq64_64_from_int">from_int</a></span> should be preferred over using <span class="code-inline"><a href="../sui_std/uq64_64#std_uq64_64_from_raw">from_raw</a></span>.
Unless the denominator is a power of two, fractions can not be represented accurately,
so be careful about rounding errors.<br/>
Aborts if the denominator is zero.<br/>
Aborts if the input is non-zero but so small that it will be represented as zero, e.g. smaller
than 2^\{-64\}.<br/>
Aborts if the input is too large, e.g. larger than or equal to 2^64.
