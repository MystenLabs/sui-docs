Every diagnostic the Move compiler can report, 162 codes in 16 categories, and the 27 lints it checks. The compiler prints a code as `EC01003`: a severity letter (`E` for an error, `W` for a warning), `C` for the compiler as the origin, then the category number and the code number. Older versions printed it without the origin letter, as `E01003`, and that form still appears in questions and issues, so both are listed.
