## What is Kiosk?

Kiosk is a decentralized system for commerce applications on Sui. Kiosk apps are a way to extend the functionality of Sui Kiosk while keeping the core functionality intact.

The topics in this section cover:

- Basic kiosk apps
- Permissioned kiosk apps
- UID access through `uid_mut` (using `kiosk::uid_mut_as_owner`)
- The Kiosk Apps API

## What do Kiosk apps leave intact?

Kiosk apps add features on top of a kiosk without discarding or blocking its base behavior. The base behavior that stays in place includes:

- **True ownership:** Only the kiosk owner can `place`, `take`, `list`, and perform other actions on assets in the kiosk.
- **Default trading flow:** The `list` and `purchase` flow remains available.
- **Creator control:** Every transaction with a third party creates a `TransferRequest`, so creators stay in control of the trading experience.

Only the kiosk owner can install an app, and installation requires the `KioskOwnerCap`. An installed app receives a permission bitmap for protected actions such as `place` and `lock`, or no permissions at all. The owner can disable an app at any time, which stops it from performing protected actions.
