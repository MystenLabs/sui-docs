## How do I swap tokens through DeepBook?

To swap tokens through DeepBook, call one of the swap functions that the `Pool` exposes. You can pass `Coin` objects directly or use a `BalanceManager`. DeepBook provides a swap-like interface commonly seen in automatic market makers (AMMs). Unlike the order functions, you can call `swap_exact_quantity` without a `BalanceManager`. You call it directly with `Coin` objects instead. The direction of the swap determines which input must be zero:

| Direction | `base_in` | `quote_in` |
| --- | --- | --- |
| Base → quote | Positive | Zero |
| Quote → base | Zero | Positive |

Swaps pay trading fees in DEEP tokens. When you swap with `Coin` objects, you provide a `deep_in` amount to pay the fees. You can overestimate this amount, because the call returns the unused DEEP tokens at the end. The manager-based functions take fees from the DEEP that the `BalanceManager` holds instead.

You can use the `get_amount_out` endpoint to simulate a swap. The function returns the exact amount of DEEP tokens that the swap requires.

## Which swap function should I use?

Pick the function that matches how you hold funds and which direction you swap:

| If you | Use |
| --- | --- |
| Swap base for quote with `Coin` objects, without a `BalanceManager` | `swap_exact_base_for_quote` |
| Swap quote for base with `Coin` objects, without a `BalanceManager` | `swap_exact_quote_for_base` |
| Set the direction yourself with `Coin` objects | `swap_exact_quantity`, with either the base or the quote input at zero value |
| Swap base for quote with a `BalanceManager` that holds enough DEEP for fees | `swap_exact_base_for_quote_with_manager` |
| Swap quote for base with a `BalanceManager` that holds enough DEEP for fees | `swap_exact_quote_for_base_with_manager` |

`swap_exact_base_for_quote` and `swap_exact_quote_for_base` both require some DEEP for fees. You can overestimate it, and the call returns the remainder. `swap_exact_quantity_with_manager` is the underlying function that both manager-based functions call.

## API

Following are the endpoints that the `Pool` exposes for swaps.

<details>
<summary>Swap exact base for quote</summary>

Swap exact base quantity without needing a `balance_manager`. DEEP quantity can be overestimated. Returns three `Coin` objects:

- `BaseAsset`: any base quantity left over because the input does not divide evenly by lot size
- `QuoteAsset`: the quote received from the swap
- `DEEP`: the unused DEEP

Some base quantity might remain if the input quantity does not divide evenly by lot size.

You can overestimate the amount of DEEP required. The call returns the remaining balance.

<summary>Swap exact quantity</summary>

The previous two functions call this function and pass `coin::zero()`, a `Coin` object with zero value, for the input they do not use. You can call it directly to swap base for quote or quote for base, as long as either the base input or the quote input has zero value.
