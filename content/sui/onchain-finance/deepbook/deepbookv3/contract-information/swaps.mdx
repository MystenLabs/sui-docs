## How do I swap tokens through DeepBook?

DeepBook provides a swap-like interface commonly seen in automatic market makers (AMMs). Unlike the order functions, you can call `swap_exact_amount` without a `BalanceManager`. You call it directly with `Coin` objects instead. The direction of the swap determines which input must be zero:

| Direction | `base_in` | `quote_in` |
| --- | --- | --- |
| Base → quote | Positive | Zero |
| Quote → base | Zero | Positive |

Some `deep_in` amount is required to pay for trading fees. You can overestimate this amount, because the call returns the unused DEEP tokens at the end.

You can use the `get_amount_out` endpoint to simulate a swap. The function returns the exact amount of DEEP tokens that the swap requires.

## Which swap function should I use?

- To swap with `Coin` objects directly, without a `BalanceManager`, use `swap_exact_base_for_quote` or `swap_exact_quote_for_base`. Both require some DEEP for fees; you can overestimate it and the call returns the remainder.
- To set the direction yourself, call `swap_exact_quantity` directly, with either the base or the quote input at zero value.
- If you use a `BalanceManager` that holds enough DEEP for fees, use `swap_exact_base_for_quote_with_manager` or `swap_exact_quote_for_base_with_manager`. `swap_exact_quantity_with_manager` is the underlying function that both call.

## API

Following are the endpoints that the `Pool` exposes for swaps.

<details>
<summary>Swap exact base for quote</summary>

Swap exact base quantity without needing a `balance_manager`. DEEP quantity can be overestimated. Returns three `Coin` objects:

- `BaseAsset`: any base quantity left over because the input does not divide evenly by lot size
- `QuoteAsset`: the quote received from the swap
- `DEEP`: the unused DEEP

Some base quantity might remain if the input quantity does not divide evenly by lot size.

You can overestimate the amount of DEEP required. The call returns the remaining balance.

Swap exact quote quantity without needing a `balance_manager`. You can overestimate DEEP quantity. Returns three `Coin` objects:

- `BaseAsset`: the base received from the swap
- `QuoteAsset`: any quote quantity left over because the input is not divisible by lot size
- `DEEP`: the unused DEEP

Some quote quantity could be left over if the input quantity is not divisible by lot size.
