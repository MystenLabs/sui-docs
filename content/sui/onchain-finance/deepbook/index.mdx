DeepBook is Sui's native liquidity layer, providing a central limit order book for spot trading, margin trading, and prediction markets.

DeepBookV3 is a Move package on Sui Mainnet, and every integration calls the same public functions, so your first decision is not which features you use, but where your code runs. Before you build, decide how your code calls DeepBook. You can depend on the DeepBookV3 Move package from your own Move module, compose transactions with the TypeScript SDK, or read market data without signing transactions. See [Choose your integration model](/onchain-finance/deepbook/deepbookv3/deepbook#which-integration-model-should-i-choose) to compare the options.
